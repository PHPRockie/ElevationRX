How it works:
  • Left panel: search + filter by group → click + to add skill to next empty slot
  • Each skill shows form buttons (Tuck / Pike / Straight) — pick the form to lock in the DD value
  • DD total updates live at the bottom as skills are added
  • Max 10 skills — once full, the + buttons disable
  • Skills can be reordered by drag-and-drop (or up/down arrows as fallback)
