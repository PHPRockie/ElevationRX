What gets built in Phase 1

  • Login form — email + password via Supabase auth
  • CoachContext — after login, looks up coach record by UID, stores gym_id in React context
  • ProtectedRoute — redirects to /login if not authenticated; shows spinner while loading
  • AppLayout — sidebar + page content area using React Router Outlet
  • Error state — if coach logs in but has no coaches table record, shows "contact your admin"
